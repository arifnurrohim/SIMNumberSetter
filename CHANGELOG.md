# Changelog

All notable changes to this fork are documented here.

## [1.2.4] - 2026-11-09

### Added

- Catppuccin Mocha theme with Lavender accent and a card-based UI.
- Catppuccin credit in the About card and in the README.

### Changed

- GitHub link now points to `arifnurrohim/SIMNumberSetter`.
- Donate link now points to `ko-fi.com/arifnurrohim`.
- About card restyled with Catppuccin surface colors and lavender accents.

### Removed

- Monet dynamic color support in favor of the fixed Catppuccin palette.

## [1.2.3] - 2026-11-09

### Added

- Dual SIM support: select a SIM slot and edit its number independently.
- Renamed package to `app.arifnurrohim.simsetter` ("SIM Setter").
- Automated GitHub Actions build and signed release workflows.
